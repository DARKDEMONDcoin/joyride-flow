## Phase 4 — performance + color/language finalisation (2026-08-20)

- Initial JS payload cut from 1.88 MB to 1.10 MB (-41%):
  - removed the forced `icons` manual chunk (whole lucide barrel, 581 KB, was
    downloaded before first paint because the shell renders a few icons);
  - pinned Vite's preload helper and `@babel/runtime`/`tslib` helpers to
    `react-vendor` so the shell no longer dragged the 191 KB `assistant-ui`
    chat chunk into the boot graph.
- Replaced the last neutral hardcoded hex colours in 12 components with theme
  tokens (foreground / muted-foreground / background / card / border). Brand
  colours (WhatsApp, Telegram, Facebook, Google) intentionally kept literal.
- Language audit: no user-facing Arabic strings remain. Remaining Arabic is
  only code comments and intent-detection regexes (required for Arabic input).
- Verified in-browser: /, /chat, /settings, /settings/data, /settings/skills
  load with zero console errors.
